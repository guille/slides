# slides

_This is the only non-AI-generated file in the repo. LLMs should be directed to lib/README.md_

I have long thought that people suck at making slides. This is (un?)surprisingly still true in the age of LLMs. Powerpoints have gotten slightly better, but I think in many cases people would be better off writing simple websites.

Modern web APIs allow for native controls and features (presenter mode) that work seamlessly, and the result can be much more impressive than the constrained expressiveness of pptx.

This is a (JS/TS) library generated by LLMs that allows doing that in a rather expressive way. Note this is not strictly needed, and LLMs are perfectly capable of writing the entire thing end to end (this repo is proof of that), but I believe in the usefulness of [building blocks](https://mitchellh.com/writing/building-block-economy).

The idea is to make things easy to consume from any library or framework. This repo includes a few demos using vanilla JS and a couple of different frameworks, showing off the expressiveness of web languages over Powerpoint, and even more complicated features, server-side metrics, interactive components, complex WebGL graphics... A quick primer is available on https://guillerg.dev/slides.

The repo includes a couple of demos with different frameworks (vanilla JS, svelte, astro, lit web components, htmx) showing off different capabilities.

It also includes a Python pdf exporter under (tools/)

In a deck:
- arrows/space/PgUp/PgDown to navigate
- `O` overview
- `P` presenter view
- `F` fullscreen
- `B` blackout
